
# Experiments

This directory contains the experimental implementation, model evaluation outputs, and supporting documentation for the AI in Digital Forensics research project.

## Contents

- `explore.ipynb` - Jupyter notebook containing data preparation, model implementation, training and evaluation.
- `ai_results.json` - Saved AI model evaluation results.
- `tools_data.json` - Consolidated tool comparison data.
- `snort_experiment.md` - Documentation of the Snort experiment and configuration.
