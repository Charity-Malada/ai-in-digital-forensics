AI-Powered Network Intrusion Detection Evaluation Framework

A research-driven framework for evaluating and comparing AI-powered Network Intrusion Detection Systems (NIDS) based on technical performance metrics, explainability considerations, and operational effectiveness within cybersecurity and digital forensics environments.

Overview

This project forms part of an Honours Computer Science research study focused on the intersection of Artificial Intelligence and Digital Forensics, specifically investigating how AI-powered cybersecurity tools support cybercrime investigation and response.

The framework evaluates intrusion detection tools using a structured scoring model that measures:

Detection Accuracy
False Positive Rate
Computational Overhead
Attack Type Coverage

The project is grounded in Design Science Research (DSR) methodology and aims to provide a decision-support framework for cybersecurity practitioners, particularly within the South African context where regulatory, infrastructural, and resource challenges impact AI adoption.
